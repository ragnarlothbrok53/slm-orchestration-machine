Core Idea - 
- Build an slm-orchestration engine, that takes any shit llm 1-3b param model and creates durable agentic flows with great accuracy!
- Aim is to make a lightweight open source package on pypi
- Basic usage idea - uv add <package-name>
- User get an easy API to create workflows easily these workflows, they get a set of useful predefined tools, that fit in most agentic-flows, they can select a model, add more tools, and easily create an API for running the agentic flow
